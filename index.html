hwatu

A daemon-based WebKit browser that makes visual verification nearly free for AI agents. 13 ms median window spawn, 216 ms full verify loop. MCP server over stdio, JSON over socket, human hand-off into a tiling WM. Rust + WebKitGTK 6.

gwae

A terminal multiplexer where panes never shrink: niri's scrolling tiling for CLI agents, in any terminal. An infinite 2D grid of strips, quantized scroll, OSC 133 dashboard. Single process, no daemon, no socket. macOS / Linux / Windows. Rust, MIT.

clique
