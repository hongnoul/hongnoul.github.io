Panes never shrink.

niri's scrolling tiling, for your CLI agents, in any terminal. Every multiplexer divides a fixed screen; gwae scrolls an infinite 2D grid of strips instead. One process, no daemon, OSC 133 agent-aware.

The strip

Fixed-width columns (1/4 by default, 1/3 → 1/2 → 1/4 on ⌥+r). A row that outgrows the screen scrolls past the viewport edge — it doesn't cram. Strips stack infinitely downward. Viewport rests only on column boundaries so the grid paints pixel-identically in every scroll state.

Why gwae

I run a lot of coding agents in parallel. At 2 panes, tmux is fine. At 6+, every fixed-screen tiler makes each pane smaller until nothing is readable. niri solved this on the desktop with scrolling tiling — columns keep their size and the viewport moves instead. gwae brings that model into the terminal you already use.

The entire terminal-orchestrator tier (Claude Squad, amux, dmux, workmux) rents tmux for display and owns no layout. The two projects that do own the niri strip — Séance (GTK) and tairi (macOS app) — are GUI-bound, not over SSH, not in a plain terminal. gwae is the mirror image: it is the layout.

  • no daemonyour agents already persist via --resume. A shell that must survive the terminal belongs in tmux inside a gwae pane
  • native windowsbuilds natively via ConPTY (M3 runtime verification) — tmux needs WSL
  • one processno socket, no attach/detach. Crashing one pane's emulator can't take the TUI down

Features

  • no-shrinkfixed-width columns; row scrolls past the edge. Skeleton placeholders tile the empty right side
  • quantized scrollviewport rests only on column boundaries — no slivers, no wobble, verified at 342-col hostile widths
  • agent dashboardstandard OSC 133 » ! ✓ ✗ — zero instrumentation. Hold ⌥ for minimap, ⌥+g smart-jumps
  • hot reloadGWAE_DEV_RELOAD=1 + ./scripts/hot.sh: save a file, new build swaps in place — same pid, same PTYs
  • kitty graphicskitten icat and agent screenshots render inside their pane, APC forwarded verbatim, clipped to pane rect
  • mouse, handledclick to focus, drag to copy. Full-screen apps that asked for mouse get every event in their own coords; gwae claims no wheel
  • onboardinggwae init — theme, layout, chrome with live mockup under every question. ⌥+t live-previews themes
  • cross-platformany terminal on macOS/Linux; Windows (ConPTY) builds natively. 256-color minimum, truecolor/kitty/mouse auto-detected

Agent awareness

Panes speak standard OSC 133 — zero instrumentation. Without it, a quiet-heuristic fallback still triages. » working, ! wants attention, ✓ done, ✗ failed.

Binds

Every action is an ⌥ chord (Option on macOS, Alt elsewhere). Works with Meta and with macOS Unicode glyphs (… for ⌥+;) — no toggle.

Install

$ curl -fsSL https://hongnoul.github.io/gwae/install.sh | bash  # macOS & Linux → ~/.local/bin
$ brew install hongnoul/tap/gwae
$ cargo install gwae                                           # Rust 1.85+
gwae                     # one strip, one 1/4 pane + skeletons
gwae run "claude"        # agent in col 0, rest shells
gwae init                # guided setup (re-runnable)
gwae doctor              # config + theme + layout smoke
gwae upgrade            # upgrades the way it was installed, or prints what to run

Windows: irm https://hongnoul.github.io/gwae/install.ps1 | iex · prebuilt gwae-*.tar.gz + .zip on releases with SHA-256.

Config

$XDG_CONFIG_HOME/gwae/gwae.toml (default ~/.config/gwae/gwae.toml). TOML, all keys optional. Live-reloads appearance.

default_column_width = "quarter"  # half, two-thirds, full, or 80 (cells)
content_width = 0                 # >0 = wider logical grid, pan with ⌥+←/→
default_agent = "claude"          # first pane + ⌥+; spawn this
startup_panes = 1
theme = "catppuccin-mocha"        # nord, tokyo-night, gruvbox, rose-pine, dracula …
cell_labels = true

[minimap]
mode = "off"                      # off | overlay | edge_ticks

# [theme] preset = "nord" + per-key overrides; gwae doctor validates

⌥+t previews themes live; gwae init asks the opinionated subset. Docs: CONFIG.md.

Architecture

gwae (one process)
├── Layout core (rows/strips/columns/panes) — pure, no I/O
├── Pane tasks (one per PTY: bytes → parse → grid + OSC 133)
├── Composer (coalesce damage → single 2D cell buffer)
├── Render (diff buffer → batched ANSI, sync-update markers)
├── Input (raw mode: decode keys, route to pane or ⌥)
└── Minimap / smart-jump (per-pane status → chrome)

Crates: gwae (TUI) · gwae-layout (pure grid, proptest invariants) · gwae-term (emulator facade) · gwae-testkit (fake PTYs). Full: ARCHITECTURE.md + LAYOUT-SPEC.md.
