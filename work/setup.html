About

gwae is a terminal multiplexer that keeps every pane at full size. Fixed-width columns, quantized scroll on column boundaries, strips stacked infinitely down. Hold ⌥ for the minimap — one tile per pane tinted by OSC 133 status (» working · ! needs you · ✓ done · ✗ failed) — and ⌥+g smart-jumps to where you're needed.

Single process, no daemon, no socket. Any terminal on macOS / Linux / Windows (ConPTY). 256-color minimum. Install with curl -fsSL https://hongnoul.github.io/gwae/install.sh | bash or brew install hongnoul/tap/gwae.
